# VENTRIVA - Fundraising & Deal Room Integration Workflow

## Stage Progression Lifecycle
```
Fundraising Round (Draft -> Open)
       │
       ├──> Investor Invitation / Discovery
       │
       ├──> Soft Commitment / Check Submission
       │
       ├──> Founder Commitment Acceptance
       │
       ├──> Data Room & Due Diligence Review (Phase 8)
       │
       ├──> Launch Investment Deal Room (Phase 13)
       │
       ├──> Term Sheet & Closing Checklist
       │
       └──> Investment Recorded & Funded
```

## Immutable Audit Trail
Every transition and interaction generates an immutable `FundraisingActivity` audit record with actor timestamping.
