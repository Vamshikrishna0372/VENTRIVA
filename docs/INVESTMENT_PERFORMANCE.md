# VENTRIVA Investment Performance Architecture

## Overview
Ventriva provides historical performance snapshot tracking and aggregate return analytics.

## Key Formulas
- **Total Invested Capital**: `Initial Investment + Follow-On Capital`
- **Total Value**: `Realized Value + Current Holding Value`
- **Unrealized Gain / Loss**: `Current Holding Value - Total Invested Capital`
- **MOIC Multiplier**: `Total Value / Total Invested Capital`
