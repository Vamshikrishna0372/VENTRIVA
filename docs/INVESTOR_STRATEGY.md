# VENTRIVA Investor Strategy & Mandate Architecture

## Overview
Ventriva Investor Strategy defines an investor's fund mandate, target check sizes, follow-on reserves, and sector/stage allocation limits.

## Scoring & Mandate Rules
1. **Target Capital Deployment**: Defines total fund pool.
2. **Follow-On Reserve Target**: Target percentage set aside for pro-rata growth rounds.
3. **Mandate Health Rating**: Evaluates diversification, over-deployment (>90%), and check size alignment on a 0–100 score.
